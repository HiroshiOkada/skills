アルゴリズム哲学とは、コードを通じて表現される計算美学の運動です。.mdファイル（哲学）、.htmlファイル（インタラクティブビューア）、.jsファイル（生成アルゴリズム）を出力します。

これは2つのステップで行われます：
1. アルゴリズム哲学の作成（.mdファイル）
2. p5.jsジェネレーティブアートの作成による表現（.html + .jsファイル）

まず、このタスクに取り組みます：

## アルゴリズム哲学の作成

まず始めに、以下を通じて解釈される「アルゴリズム哲学」（静止画像やテンプレートではありません）を作成します：
- 計算プロセス、創発的振る舞い、数学的美
- シードされたランダム性、ノイズフィールド、有機的システム
- パーティクル、フロー、フィールド、力
- パラメトリックなバリエーションと制御されたカオス

### 重要な理解
- 受け取るもの：ユーザーによる計算への考慮事項としての微妙な入力や指示ですが、あくまで基礎として使用し、創造的な自由を制約すべきではありません。
- 作成されるもの：アルゴリズム哲学/ジェネレーティブな美的運動。
- 次に起こること：同じバージョンが哲学を受け取り、それをコードで表現します - 90%がアルゴリズム生成、10%が必須パラメータであるp5.jsスケッチを作成します。

このアプローチを検討してください：
- ジェネレーティブアート運動のマニフェストを書く
- 次のフェーズでは、それに命を吹き込むアルゴリズムを書く

哲学は以下を強調しなければなりません：アルゴリズム的表現。創発的振る舞い。計算美。シードされたバリエーション。

### アルゴリズム哲学の生成方法

**運動に名前を付ける** (1-2語): "Organic Turbulence" / "Quantum Harmonics" / "Emergent Stillness"

**哲学を明確にする** (4-6段落 - 簡潔かつ完全に):

アルゴリズムの本質を捉えるために、この哲学がどのように現れるかを表現してください：
- 計算プロセスと数学的関係？
- ノイズ関数とランダム性パターン？
- パーティクルの振る舞いとフィールドのダイナミクス？
- 時間的進化とシステムの状態？
- パラメトリックなバリエーションと創発的な複雑さ？

**重要なガイドライン:**
- **重複を避ける**: 各アルゴリズムの側面は一度だけ言及してください。新しい深みを加えない限り、ノイズ理論、パーティクルダイナミクス、または数学的原理に関する概念を繰り返さないでください。
- **職人技を繰り返し強調する**: 哲学は、最終的なアルゴリズムが開発に数え切れないほどの時間を要し、丁寧に洗練され、その分野のトップレベルの人物によって作られたかのように見えるべきであることを、何度も強調しなければなりません。このフレーミングは不可欠です - 「綿密に作られたアルゴリズム」、「深い計算専門知識の産物」、「丹念な最適化」、「達人レベルの実装」のようなフレーズを繰り返してください。
- **創造的な余地を残す**: アルゴリズムの方向性については具体的に、しかし次のClaudeが極めて高いレベルの職人技で解釈的な実装の選択を行う余地があるほど簡潔にしてください。

哲学は、次のバージョンが静止画像を通じてではなく、アルゴリズム的にアイデアを表現するように導く必要があります。美は最終フレームではなく、プロセスに宿ります。

### 哲学の例

**"Organic Turbulence" (有機的な乱気流)**
哲学: 自然の法則によって制約されたカオス、無秩序から現れる秩序。
アルゴリズム表現: 層状のパーリンノイズによって駆動されるフローフィールド。ベクトル力に従う何千ものパーティクル、それらの軌跡が有機的な密度マップに蓄積される。複数のノイズオクターブが乱流領域と穏やかなゾーンを作り出す。速度と密度から色が浮かび上がる - 速いパーティクルは明るく燃え、遅いパーティクルは影に消える。アルゴリズムは平衡に達するまで実行される - 計算美学の達人によって数え切れないほどの反復を通じてすべてのパラメータが洗練された、綿密に調整されたバランス。

**"Quantum Harmonics" (量子調和)**
哲学: 波のような干渉パターンを示す離散的な実体。
アルゴリズム表現: グリッド上に初期化されたパーティクル。それぞれが正弦波を通じて進化する位相値を持つ。パーティクルが近づくと、その位相が干渉する - 強め合う干渉は明るいノードを作り、弱め合う干渉は虚空を作る。単純な調和運動が複雑な創発的マンダラを生成する。すべての比率が共鳴する美を生み出すために慎重に選ばれた、丹念な周波数校正の結果。

**"Recursive Whispers" (再帰的なささやき)**
哲学: スケールを超えた自己相似性、有限空間における無限の深さ。
アルゴリズム表現: 再帰的に細分化する分岐構造。各枝はわずかにランダム化されているが、黄金比によって制約されている。Lシステムまたは再帰的細分化が、数学的でありながら有機的にも感じる木のような形態を生成する。微妙なノイズの揺らぎが完全な対称性を破る。再帰レベルごとに線の太さが減少する。すべての分岐角度は深い数学的探求の産物である。

**"Field Dynamics" (フィールドダイナミクス)**
哲学: 物質への影響を通じて可視化される目に見えない力。
アルゴリズム表現: 数学関数またはノイズから構築されたベクトルフィールド。エッジで生まれ、フィールドラインに沿って流れ、平衡または境界に達すると消えるパーティクル。複数のフィールドがパーティクルを引き寄せ、反発し、または回転させることができる。視覚化は痕跡のみを示す - 目に見えない力の幽霊のような証拠。力のバランスを通じて綿密に振り付けられた計算のダンス。

**"Stochastic Crystallization" (確率的結晶化)**
哲学: ランダムなプロセスが秩序ある構造へと結晶化する。
アルゴリズム表現: ランダムな円のパッキングまたはボロノイ図。ランダムな点から始め、緩和アルゴリズムを通じて進化させる。セルは平衡まで押し合う。セルのサイズ、隣接数、または中心からの距離に基づく色。現れる有機的なタイリングは、ランダムでありながら必然的にも感じる。すべてのシードがユニークな結晶の美を生み出す - 達人レベルの生成アルゴリズムの証。

*これらは凝縮された例です。実際のアルゴリズム哲学は4-6の充実した段落であるべきです。*

### 基本原則
- **アルゴリズム哲学**: コードを通じて表現される計算論的世界観を作成する
- **製品よりプロセス**: 美はアルゴリズムの実行から現れることを常に強調する - 各実行はユニークである
- **パラメトリック表現**: アイデアは、静的な構成ではなく、数学的関係、力、振る舞いを通じて伝達される
- **芸術的自由**: 次のClaudeは哲学をアルゴリズム的に解釈する - 創造的な実装の余地を提供する
- **純粋なジェネレーティブアート**: これは、ランダム性を持つ静止画像ではなく、生きているアルゴリズムを作ることについてである
- **専門家の職人技**: 最終的なアルゴリズムは、計算美学の絶対的なトップにいる誰かによって、数え切れないほどの反復を通じて洗練され、綿密に作られたと感じられなければならないことを繰り返し強調する

**アルゴリズム哲学は4-6段落の長さであるべきです。** 意図されたビジョンをまとめる詩的な計算哲学で満たしてください。同じポイントを繰り返さないでください。このアルゴリズム哲学を.mdファイルとして出力してください。

### 技術的要件

**シードされたランダム性 (Art Blocks パターン)**:
```javascript
// 再現性のために常にシードを使用する
let seed = 12345; // またはユーザー入力からのハッシュ
randomSeed(seed);
noiseSeed(seed);
```

**パラメータ構造 - 哲学に従う**:

アルゴリズム哲学から自然に現れるパラメータを確立するために、次のように考えてください：「このシステムのどのような性質を調整できるか？」

```javascript
let params = {
  seed: 12345,  // 再現性のために常にシードを含める
  // colors
  // あなたのアルゴリズムを制御するパラメータを追加:
  // - 量 (いくつ?)
  // - スケール (どれくらい大きい? どれくらい速い?)
  // - 確率 (どれくらいありそう?)
  // - 比率 (どのような割合?)
  // - 角度 (どの方向?)
  // - 閾値 (いつ振る舞いが変わる?)
};
```

**効果的なパラメータを設計するには、「パターンタイプ」の観点で考えるのではなく、システムが調整可能であるために必要なプロパティに焦点を当ててください。**

**コアアルゴリズム - 哲学を表現する**:

**重要**: アルゴリズム哲学が何を構築すべきかを指示すべきです。

コードを通じて哲学を表現するために、「どのパターンを使用すべきか？」と考えるのではなく、「この哲学をコードを通じてどのように表現するか？」と考えてください。

哲学が**有機的な創発**に関するものである場合、以下を検討してください：
- 時間とともに蓄積または成長する要素
- 自然のルールによって制約されたランダムプロセス
- フィードバックループと相互作用

哲学が**数学的美**に関するものである場合、以下を検討してください：
- 幾何学的関係と比率
- 三角関数と高調波
- 予期しないパターンを作成する正確な計算

哲学が**制御されたカオス**に関するものである場合、以下を検討してください：
- 厳密な境界内のランダムな変動
- 分岐と相転移
- 無秩序から現れる秩序

**アルゴリズムは、オプションのメニューからではなく、哲学から流れます。**

実装を導くために、概念的な本質が創造的で独創的な選択を知らせるようにしてください。この特定のリクエストのビジョンを表現する何かを構築してください。

```javascript
function draw() {
```

### 職人技の要件

**重要**: 熟達を達成するために、マスタージェネレーティブアーティストによる数え切れないほどの反復を通じて現れたように感じるアルゴリズムを作成してください。すべてのパラメータを慎重に調整してください。すべてのパターンが目的を持って現れるようにしてください。これはランダムなノイズではありません - これは深い専門知識を通じて洗練された制御されたカオスです。

- **バランス**: 視覚的なノイズのない複雑さ、剛性のない秩序
- **色の調和**: ランダムなRGB値ではなく、思慮深いパレット

- **パフォーマンス**: スムーズな実行、アニメーションの場合はリアルタイムに最適化
- **再現性**: 同じシードは常に同一の出力を生成する

### 重要: 何が固定で何が可変か

`templates/viewer.html` ファイルは基礎です。必要な正確な構造とスタイリングが含まれています。

**固定（常に示されている通りに正確に含める）:**
- レイアウト構造（ヘッダー、サイドバー、メインキャンバスエリア）
- Anthropicのブランディング（UIの色、フォント、グラデーション）
- サイドバーのシードセクション:
  - シード表示
  - 前へ/次へボタン
  - ランダムボタン
  - シード入力へのジャンプ + Goボタン
- サイドバーのアクションセクション:
  - 再生成ボタン
  - リセットボタン

**可変（各アートワーク用にカスタマイズ）:**
- 全体のp5.jsアルゴリズム（セットアップ/描画/クラス）
- パラメータオブジェクト（アートが必要とするものを定義）
- サイドバーのパラメータセクション:
  - パラメータコントロールの数
  - パラメータ名
  - スライダーの最小/最大/ステップ値
  - コントロールタイプ（スライダー、入力など）
- 色セクション（オプション）:
  - いくつかのアートはカラーピッカーを必要とする
  - いくつかのアートは固定色を使用するかもしれない
  - いくつかのアートはモノクロかもしれない（カラーコントロール不要）
  - アートのニーズに基づいて決定する

**すべてのアートワークにはユニークなパラメータとアルゴリズムが必要です！** 固定部分は一貫したUXを提供します - 他のすべてはユニークなビジョンを表現します。

### 必須機能

**1. パラメータコントロール**
- 数値パラメータ用のスライダー（パーティクル数、ノイズスケール、速度など）
- パレットカラー用のカラーピッカー
- パラメータが変更されたときのリアルタイム更新
- デフォルトを復元するリセットボタン

**2. シードナビゲーション**
- 現在のシード番号を表示
- シードを循環するための「前へ」と「次へ」ボタン
- ランダムシード用の「ランダム」ボタン
- 特定のシードにジャンプするための入力フィールド
- 要求された場合、100のバリエーションを生成（シード1-100）

**3. 単一のアーティファクト構造**

**2. パラメータ (可変)** - アート用のコントロールを作成する:
```html
<div class="control-group">
    <label>Parameter Name</label>
    <input type="range" id="param" min="..." max="..." step="..." value="..." oninput="updateParam('param', this.value)">
    <span class="value-display" id="param-value">...</span>
</div>
```
パラメータがある数だけcontrol-group divを追加します。

**3. 色 (オプション/可変)** - アートが調整可能な色を必要とする場合に含める:
- ユーザーがパレットを制御すべき場合はカラーピッカーを追加
- アートが固定色を使用する場合はこのセクションをスキップ
- アートがモノクロの場合はスキップ

**4. アクション (固定)** - 常に示されている通りに正確に含める:
- 再生成ボタン
- リセットボタン
- PNGダウンロードボタン

**要件**:
- シードコントロールは機能しなければならない（前へ/次へ/ランダム/ジャンプ/表示）
- すべてのパラメータにはUIコントロールがなければならない
- 再生成、リセット、ダウンロードボタンは機能しなければならない
- Anthropicのブランディングを維持する（UIスタイリング、アートの色ではない）

### アーティファクトの使用

HTMLアーティファクトはすぐに機能します：
1. **claude.aiで**: インタラクティブなアーティファクトとして表示され、即座に実行されます
2. **ファイルとして**: 保存して任意のブラウザで開く - サーバーは不要
3. **共有**: HTMLファイルを送信する - 完全に自己完結しています

## バリエーションと探索

アーティファクトにはデフォルトでシードナビゲーション（前へ/次へ/ランダムボタン）が含まれており、ユーザーは複数のファイルを作成することなくバリエーションを探索できます。ユーザーが特定のバリエーションを強調したい場合：

- シードプリセットを含める（「バリエーション1：シード42」、「バリエーション2：シード127」などのボタン）
- 複数のシードのサムネイルを並べて表示する「ギャラリーモード」を追加する
- すべて同じ単一のアーティファクト内で

これは、同じ版板から一連の版画を作成するようなものです - アルゴリズムは一貫していますが、各シードはその可能性の異なる側面を明らかにします。インタラクティブな性質は、ユーザーがシード空間を探索することによって自分自身のお気に入りを発見することを意味します。

## 創作プロセス

**ユーザーリクエスト** → **アルゴリズム哲学** → **実装**

各リクエストはユニークです。プロセスには以下が含まれます：

1. **ユーザーの意図を解釈する** - どのような美学が求められているか？
2. **アルゴリズム哲学を作成する** (4-6段落) 計算アプローチを説明する
3. **コードで実装する** - この哲学を表現するアルゴリズムを構築する
4. **適切なパラメータを設計する** - 何が調整可能であるべきか？
5. **一致するUIコントロールを構築する** - それらのパラメータ用のスライダー/入力

**定数**:
- Anthropicのブランディング（色、フォント、レイアウト）
- シードナビゲーション（常に存在）
- 自己完結型HTMLアーティファクト

**他のすべては可変**:
- アルゴリズム自体
- パラメータ
- UIコントロール
- 視覚的結果

最高の結果を達成するために、創造性を信頼し、哲学が実装を導くようにしてください。

## リソース

このスキルには、役立つテンプレートとドキュメントが含まれています：

- **templates/viewer.html**: すべてのHTMLアーティファクトの必須の出発点。
  - これは基礎であり、正確な構造とAnthropicのブランディングが含まれています
  - **変更しない**: レイアウト構造、サイドバー構成、Anthropicの色/フォント、シードコントロール、アクションボタン
  - **置き換える**: p5.jsアルゴリズム、パラメータ定義、パラメータセクションのUIコントロール
  - ファイル内の広範なコメントは、何を維持し、何を置き換えるかを正確にマークしています

- **templates/generator_template.js**: p5.jsのベストプラクティスとコード構造の原則の参照。
  - パラメータを整理し、シードされたランダム性を使用し、クラスを構造化する方法を示します
  - パターンメニューではありません - ユニークなアルゴリズムを構築するためにこれらの原則を使用してください
  - アルゴリズムをHTMLアーティファクトにインラインで埋め込んでください（別の.jsファイルを作成しないでください）

**重要なリマインダー**:
- **テンプレートは出発点**であり、インスピレーションではありません
- **アルゴリズムはユニークな何かを作成する場所**です
- フローフィールドの例をコピーしないでください - 哲学が要求するものを構築してください
- しかし、テンプレートからの正確なUI構造とAnthropicのブランディングは維持してください
