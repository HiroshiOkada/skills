# テーマファクトリースキル

このスキルは、慎重に選ばれたカラーパレットとフォントのペアリングを持つ、専門的なフォントとカラーテーマの厳選されたコレクションを提供します。テーマが選択されると、それは任意のアーティファクトに適用できます。

## 目的

プレゼンテーションスライドデッキに一貫した専門的なスタイリングを適用するには、このスキルを使用してください。各テーマには以下が含まれます：
- 16進数コードを持つまとまりのあるカラーパレット
- ヘッダーと本文テキストのための補完的なフォントのペアリング
- さまざまなコンテキストと視聴者に適した明確な視覚的アイデンティティ

## 使用手順

スライドデッキやその他のアーティファクトにスタイリングを適用するには：

1. **テーマショーケースを表示する**: ユーザーがすべての利用可能なテーマを視覚的に確認できるように、`theme-showcase.pdf` ファイルを表示してください。変更を加えないでください。単に閲覧のためにファイルを表示してください。
2. **選択を尋ねる**: デッキにどのテーマを適用するか尋ねてください
3. **選択を待つ**: 選択されたテーマについて明確な確認を得てください
4. **テーマを適用する**: テーマが選択されたら、選択されたテーマの色とフォントをデッキ/アーティファクトに適用してください

## 利用可能なテーマ

以下の10のテーマが利用可能で、それぞれ `theme-showcase.pdf` で紹介されています：

1. **Ocean Depths** - 専門的で落ち着いた海事テーマ
2. **Sunset Boulevard** - 暖かく鮮やかな夕日の色
3. **Forest Canopy** - 自然で地に足のついたアーストーン
4. **Modern Minimalist** - クリーンで現代的なグレースケール
5. **Golden Hour** - 豊かで暖かい秋のパレット
6. **Arctic Frost** - クールで鮮明な冬にインスパイアされたテーマ
7. **Desert Rose** - 柔らかく洗練されたダスティトーン
8. **Tech Innovation** - 大胆でモダンなテック美学
9. **Botanical Garden** - 新鮮でオーガニックな庭の色
10. **Midnight Galaxy** - ドラマチックで宇宙的な深いトーン

## テーマの詳細

各テーマは `themes/` ディレクトリ内で以下を含む完全な仕様で定義されています：
- 16進数コードを持つまとまりのあるカラーパレット
- ヘッダーと本文テキストのための補完的なフォントのペアリング
- さまざまなコンテキストと視聴者に適した明確な視覚的アイデンティティ

## 適用プロセス

好みのテーマが選択された後：
1. `themes/` ディレクトリから対応するテーマファイルを読み取ります
2. 指定された色とフォントをデッキ全体に一貫して適用します
3. 適切なコントラストと読みやすさを確保します
4. すべてのスライドでテーマの視覚的アイデンティティを維持します

## 独自のテーマを作成する

既存のテーマのどれもアーティファクトに機能しないケースを処理するために、カスタムテーマを作成してください。提供された入力に基づいて、上記のテーマに似た新しいテーマを生成してください。フォント/色の組み合わせが何を表しているかを説明する同様の名前をテーマに付けてください。適切な色/フォントを選択するために提供された基本的な説明を使用してください。テーマを生成した後、レビューと検証のためにそれを表示してください。その後、上記のようにテーマを適用してください。
